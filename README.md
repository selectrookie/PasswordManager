# PasswordManager
Password Manager with Pandas, Cryptography and Tkinter. Learning Project.

Este proyecto es un trabajo pequeño para aprender a cómo crear .csv con Pandas y, al mismo tiempo, poder añadir funciones de encriptado con cryptography y hacer una interfaz sencilla en el futuro con Tkinter para aprender cómo funcionan estas dos bibliotecas.

ARCHIVOS:

---CONTRASEÑAS.py

-Código principal y sencillo usando la biblioteca de Pandas. Genera un csv de contraseñas y tiene las funciones de Añadir, Buscar y Eliminar.
